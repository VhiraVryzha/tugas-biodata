# Tugas 1 - Pemrograman Web: Profil Biodata

Halaman ini berisi profil biodata singkat yang dibuat menggunakan HTML.

## Cara Melihat Hasilnya
Buka file [`biodata.html`](./biodata.html) langsung di browser, atau aktifkan **GitHub Pages** pada repository ini untuk melihatnya secara online.

## Kode HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title>Profil Biodata</title>
</head>

<body>

    <h1>Profil Biodata</h1>

    <h2>Data Diri</h2>

    <p><strong>Nama:</strong> Zafira Paras</p>
    <p><strong>Tempat, Tanggal Lahir:</strong> Pangkalpinang, 9 Mei 2007</p>
    <p><strong>Jenis Kelamin:</strong> Perempuan</p>
    <p><strong>Program Studi:</strong> Sistem Teknologi Informasi</p>
    <p><strong>Semester:</strong> 2</p>
    <p><strong>Hobi:</strong> Memasak dan mendengarkan musik</p>

    <h2>Tentang Saya</h2>

    <p>
        Saya adalah seorang mahasiswa yang sedang mempelajari
        teknologi informasi dan pemrograman web.
    </p>

</body>
</html>
```

## Penjelasan Elemen HTML yang Digunakan

| Elemen | Fungsi |
|---|---|
| `<!DOCTYPE html>` | Menyatakan bahwa dokumen ini adalah HTML5 |
| `<html>` | Elemen pembungkus seluruh halaman |
| `<head>` | Berisi informasi halaman yang tidak tampil langsung di layar |
| `<title>` | Judul halaman, muncul di tab browser ("Profil Biodata") |
| `<body>` | Berisi seluruh konten yang tampil di layar |
| `<h1>` | Judul utama halaman ("Profil Biodata") |
| `<h2>` | Sub-judul, digunakan dua kali untuk "Data Diri" dan "Tentang Saya" |
| `<p>` | Paragraf, digunakan untuk menampilkan tiap baris data diri dan paragraf cerita |
| `<strong>` | Menebalkan teks (bold), dipakai pada label seperti "Nama:", "Hobi:", dsb |

## Penjelasan Atribut yang Digunakan

Kode ini sengaja ditulis sederhana tanpa atribut tambahan seperti `class` atau `id`, karena semua tampilan menggunakan gaya bawaan (default) dari browser. Tidak ada atribut eksplisit yang digunakan pada tag-tag di atas.
